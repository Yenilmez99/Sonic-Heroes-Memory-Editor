# 🇺🇸 English

![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

The project is licensed under MIT License.

A memory editor tool for **Sonic Heroes**.  
It allows you to inspect and modify runtime memory values to tweak game behavior.

---

## ✨ Features

- Modify values (health, positions)  
- Lightweight and easy to use  
- Compatible with Windows and Linux

---

## 📥 Installation & Usage

1. Download the latest release (`.zip` or executable) from the Releases page  
3. Run the editor  
4. Launch **Sonic Heroes**

> ⚠️ Warning: Changing memory may cause crashes.  

---

## 🛠 Requirements

- Windows 10 or above
- Linux Kernel 7+ (It likely works on older versions, but it was tested on Linux 7.2.0)
- A working Sonic Heroes installation  

---

## ❓ FAQ

**Q:** Does it work with modded game versions?  
**A:** It might — depends on whether the mod changes memory layout.
